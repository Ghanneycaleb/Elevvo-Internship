# The Curious Journal

**Elevvo Internship · Task 04 · Level 2**

A responsive, static journal page built with HTML, CSS, and vanilla JavaScript. It uses fictional sample posts and has no backend.

## Features

- Browse sample posts about technology, travel, and food.
- Filter posts by category or search by title.
- Navigate results with three posts per page.
- Show an empty state when no posts match.
- Build post cards with DOM methods and provide a fallback when a remote image cannot load.

## Run locally

Open `index.html` in a browser, or serve this folder with VS Code Live Server. No package installation, build step, or backend is required.

## Project files

- `index.html` — journal structure, navigation, filters, search, and pagination controls.
- `style.css` — responsive presentation and visual styles.
- `script.js` — sample post data, filtering, search, rendering, and pagination.

Post images are loaded from Unsplash and require an internet connection. If an image is unavailable, the page displays a fallback.
