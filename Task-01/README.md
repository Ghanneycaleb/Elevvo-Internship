# SlideBar

**Elevvo Internship · Task 01 · Level 1**

A focused, responsive demo of a collapsible sidebar built with HTML, CSS, and vanilla JavaScript.

## Features

- Expand and collapse the sidebar on desktop.
- Open it as a mobile drawer with a backdrop.
- Close the mobile drawer with the close control, backdrop, or Escape key.
- Keyboard-accessible controls and focus handling.

## Run locally

Open `index.html` in a browser, or serve this folder with VS Code Live Server. No package installation, build step, or backend is required.

## Project files

- `index.html` — page structure and sidebar controls.
- `style.css` — responsive layout and sidebar styles.
- `script.js` — desktop and mobile sidebar behavior.
